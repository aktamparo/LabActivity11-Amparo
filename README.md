# Barangay Bulletin – Purok Amparo

This Laravel application is a small bulletin for community announcements.

## Personalization

- Posts per page: 6, because “Amparo” has six letters.
- Custom category: Education.
- Birthday post date: January 1, 2026.
- The pinned post is “Purok Amparo Clean-up Drive”.
- Tags: Purok Amparo, Urgent, Libre, Schedule, and Announcement.
- The pinned post has at least three seeded comments, including one from Lola Amparo.

Eight additional resident users are generated by `UserFactory`.

## Relationships

- `User` has one `Author` profile and has many `Comment` records.
- `Author` belongs to `User`, has many `Post` records, and has many comments through posts.
- `Post` belongs to `Author`, has many `Comment` records, and belongs to many `Tag` records through `post_tag`.
- `Comment` belongs to both `Post` and `User`.
- `Tag` belongs to many `Post` records through `post_tag`.

## Running the project

PowerShell:

```powershell
composer install
Copy-Item .env.example .env
php artisan key:generate
php artisan migrate:fresh --seed
npm install
npm run dev
php artisan serve
```

The login page is available at `/login`, and successful login redirects to `/posts`.
